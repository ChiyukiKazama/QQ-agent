# 自主表情回应

在“插件”页开关。此扩展复用已存在的 `send_reaction` 工具，不增加同名工具或第二条发送路径。普通群聊里“没被 @、不适合插话”时，明确引导模型考虑消息气泡下方的小表情；需要具体回答的消息仍正常回答，没有合适内容仍可以不回应。

使用 `before-context` 记录本轮未读群友消息的合法 ID，随后通过 `before-llm-messages` 在请求末尾补充本轮提示。只在现有会话已经触发后工作，沿用全局／分群响应档位与概率，没有后台轮询、额外模型调用或独立频率。静态引导放在动态技能片段位置，本轮 ID 放在请求末尾，保留已有提示词前缀。

直接被 @／拍一拍、私聊、主动定时机会不添加普通消息提示；自发消息、已撤回条目、无效消息 ID 不进入候选。关闭消息工具总开关、消息分类或 `send_reaction` 后，引导和钩子一起停用。模型决定贴表情后仍经过原有消息归属校验、发送队列、限频、去重及成功存档。

选择插件形态是因为这里只补充处理钩子与提示规则，已有内置工具负责执行；不需要再注册一个重复的技能工具。模型自主选择，不承诺每条普通消息都贴表情。
